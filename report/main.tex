\section*{Abstract}
This project analyses Singapore's five-minute rainfall records from 2017 to
2024 and develops a distributed Spark pipeline for 30-minute rainfall
exceedance prediction. After cleaning the NEA data and accounting for missing
observations and changing station coverage, wet-reading frequency was found to
range from 1.94\% to 3.20\% across the eight years, with a recurring afternoon
peak.

For prediction, we compared several MLlib models using station, time, rainfall
threshold and recent same-station rainfall history, with separate periods for
training, validation, model selection, calibration and final testing. The
selected gradient-boosted tree model was retrained on 34.5 million valid
2017-2022 windows and evaluated on 6.37 million held-out 2024 windows. At the
0.5~mm threshold, it achieved a PR-AUC of 0.6345 and a Brier score of 0.01958,
compared with 0.0732 and 0.03436 for the climatology baseline. Recent rainfall
history provided the largest predictive gain. Isotonic calibration improved
agreement between predicted probabilities and observed frequencies relative
to raw scores, while PAVA enforced consistency across rainfall thresholds.
The model's Brier improvement over climatology narrowed as the rainfall
threshold increased, and recall at 10~mm was only 19.3\% at a 0.5 probability
cutoff. These results support short-horizon risk estimation while identifying
heavy exceedances and windows with zero observed recent rain as priorities
for improvement. Core data processing, model fitting and scoring ran on a
distributed Google Cloud Dataproc cluster using Spark DataFrames and MLlib.

\section{Introduction}
Rainfall observations were taken from the National Environment Agency's
Historical Rainfall across Singapore collection and use Singapore Time. The
dataset documentation notes that some observations may be missing and that the
records have not undergone climate-record quality control~\cite{nea}.

Task 1 uses the full 2017-2024 period. For Task 2, the data were split
chronologically to avoid using future information during model development:
2017-2020 for hyperparameter training, 2021 for validation, 2022 for model
selection, 2023 for probability calibration, and 2024 for final evaluation.
After model selection, the chosen model was refitted using all valid windows
from 2017-2022.

\section{Data and cleaning}
\subsection{Input and timestamp handling}
The eight annual files contain 48,538,713 rows and 12 columns. Rainfall is
recorded using NEA reading type \texttt{TB1 Rainfall 5 Minute Total F}, in
millimetres. We treat each reading at time $t$ as the rainfall accumulated over
the preceding five minutes, $(t-5\text{ min},t]$. This is an analysis
convention because NEA does not explicitly define the timestamp semantics in
the dataset documentation.

A timestamp inconsistency appears in the earlier records. Many observations
from early 2017 end at second 59, while later 2017 records and those from
2018-2024 end at second 00. The same \texttt{:59} pattern also appears in the
official 2016 dataset~\cite{nea}. In 2017, 3,480,779 timestamps fell exactly on
five-minute boundaries and 1,775,327 were one second earlier. We therefore
shifted only this systematic \texttt{:59} pattern forward by one second to
align the timestamps, while preserving the original timestamps for audit
purposes. Other off-grid timestamps were rejected. The reason for the change
is not documented by NEA.

We then validated parsing, station identifiers, timestamps, rainfall values,
source year, reading type and unit. Rainfall values were required to be
nonnegative. Duplicate station-time records were resolved deterministically,
and coordinates were used only for the supplementary spatial analysis.
Missing observations were kept as gaps rather than being replaced with zero.

\subsection{Coverage definitions}
Coverage was calculated as the number of retained five-minute observations
divided by the number expected over the full calendar period, using 288 slots
per day. Periods with no records therefore reduce coverage. Rainfall occurrence
was defined as the proportion of retained observations with rainfall greater
than zero; missing observations were excluded rather than treated as dry.
Conditional wet intensity was the mean rainfall amount among positive
observations. Monthly rainfall totals were computed from the observations
available for each station-month and were not adjusted for missing slots.

To reduce the effect of incomplete records, monthly analyses included only
station-months with at least 95\% coverage, with each eligible station-month
given equal weight. Hourly analyses used the same monthly criterion and
additionally required at least 95\% coverage for each station-month-hour, based
on 12 expected five-minute observations per day for that hour. Eligible
station-month-hour summaries were then averaged with equal weight. Since
station availability changed over time, these summaries describe the observed
monitoring network rather than a fixed set of stations.

A complete station-day was defined as one containing all 288 expected
five-minute observations. For the supplementary complete-day analysis, daily
rainfall totals were first averaged within each station-month, and contributing
station-months were then weighted equally. The complete-day fraction was
calculated against all expected station-days for station IDs observed at any
point from 2017 to 2024, so it captures both missing observations and changes
in station availability.

\section{Task 1: Rainfall patterns}
We examine how often rain is recorded, how much falls when it rains, and how
these patterns vary over time. Coverage checks establish which comparisons
the changing station network can support.

\subsection{Across-year distribution}
The annual summaries use each retained five-minute reading as one observation.
Wet frequency is the fraction of readings greater than zero. It was lowest in
2019 (1.94\%) and highest in 2023 (3.20\%). Conditional wet-reading mean was
between 0.83 and 0.91~mm across the years. The maximum retained reading ranged
from 15.4~mm in 2019 to 37.2~mm in 2022. These annual summaries use all valid
records, while station coverage varies across years.
Table~\ref{tab:annual-distribution} reports the annual values, and
Figure~\ref{fig:distribution} shows the distribution and wet-reading tail.

Mean rainfall per valid reading equals wet frequency multiplied by conditional
wet intensity. The comparatively stable wet means therefore suggest that
occurrence explains much of the annual variation: 2019 had fewer wet readings,
rather than unusually weak readings when wet. The comparison with 2023 makes
this distinction clear. Their wet-reading means were almost identical
(0.847 and 0.849~mm), but their wet frequencies were 1.94\% and 3.20\%.
Consequently, their means over all valid readings differed substantially:
0.0164 versus 0.0272~mm. Conversely, 2022 had a slightly lower wet frequency
than 2023 but a higher overall mean, because its wet readings were stronger
on average.

Between 96.80\% and 98.06\% of retained readings were zero in each year.
Among wet readings, most amounts were small, with a long upper tail
(Figure~\ref{fig:distribution}). The 37.2~mm maximum in 2022 identifies an
unusual reading; the tail frequencies below show how common large readings
were.

\subsection{Within-year monthly and hourly patterns}
For eligible station-months, mean observed monthly rainfall ranged from
31.97~mm (February 2021) to 419.07~mm (October 2022). Monthly wet frequency
ranged from 0.37\% (August 2019) to 7.07\% (January 2024).

Conditional wet intensity also varied by month. Across the eligible
year-month summaries, it averaged 1.05~mm in March and 1.02~mm in April,
compared with 0.69~mm in January; support ranged from six to eight years per
calendar month. Individual summaries ranged from 0.58~mm (December 2019) to
1.35~mm (March 2019).

January had the highest wet frequency in some years, while March and April
had larger average wet-reading amounts across the available years.
Monthly totals combine frequency, intensity and the number of observed
slots, so a large total can result from frequent rain, heavier readings,
or both.

The equal-weight hourly summaries peaked at 15:00 in five years and 16:00 in
the other three. Peak-hour frequencies ranged from 3.42\% in 2019 to 7.76\%
in 2023. The extrema of the monthly station averages are listed in
Table~\ref{tab:monthly-extrema};
Figures~\ref{fig:monthly} and~\ref{fig:hourly} show monthly intensity,
frequency and within-day patterns.

The afternoon peak recurs more consistently than the month with the highest
wet frequency. This supports considering time-of-day features in Task 2,
while the changing peak magnitude indicates that calendar information alone
cannot describe all rainfall variability.

This recurring afternoon concentration is consistent with the Meteorological
Service Singapore's description of daytime rainfall and afternoon thunderstorms
associated with surface heating~\cite{mss-climate}. Its long-term account also
identifies higher rainfall from November to January and a relatively dry
February.

\subsection{Network coverage and annual comparison}
Annual coverage uses each ID's full calendar year; a station-year without
readings has zero coverage. No ID met any of the 90\%, 95\% or 99\% cutoffs in
all eight years, leaving no fixed-ID cohort. The annual comparisons therefore
use each year's available network. A screen of coordinates, station names and
device IDs found no obvious replacements or co-located IDs.
Figure~\ref{fig:coverage} shows station-year coverage.

The blocks of low or absent coverage explain why raw network totals would mix
rainfall differences with station availability. Coverage filtering reduces
incomplete-record effects, but does not make the contributing stations
identical across years.
For example, a low annual coverage value may reflect a station that operated
for only part of the year, as well as missing readings during operation.
Neither case is evidence of dry weather. This is why the annual occurrence
rates use retained readings as their denominator, while coverage is reported
separately. Even with this separation, missingness related to rainfall could
change the observed frequencies.

\section{Task 2: Thirty-minute exceedance probability}
Task 2 tests whether current and recent station readings improve on
calendar-based rainfall probabilities. Evaluation covers discrimination,
probability accuracy and classification at a fixed probability cutoff.

\subsection{Target and features}
Each candidate is an observed station-time pair with a valid current rainfall
reading. Let $r(s,u)$ denote rainfall observed at station $s$ at time $u$.
For threshold $\tau$, the 30-minute accumulation and exceedance label are
\[
  \begin{aligned}
    F_{30}(s,t)
    &= \sum_{j=1}^{6} r(s,t+5j\,\mathrm{min}),\\
    y(s,t,\tau)
    &= \mathbf{1}\left[F_{30}(s,t) > \tau\right].
  \end{aligned}
\]
The sum contains exactly six future observations at $t+5$ through $t+30$
minutes for the same station. All six must exist at their exact five-minute
timestamps; a sample missing any future observation is excluded, and missing
rainfall is not replaced by zero. The current reading is not part of the
target. Equality to $\tau$ is a non-exceedance.

The model estimates
\[
  \hat p(s,t,\tau)=\widehat{\Pr}\!\left(
  F_{30}(s,t)>\tau\mid X(s,t),\tau\right),
  \qquad 0.2\leq\tau\leq10\text{ mm}.
\]
A single model takes the requested threshold as an input. We require its
predicted exceedance probability to be non-increasing in the threshold: for
$\tau_1<\tau_2$,
\[
  \hat p(s,t,\tau_1)\geq\hat p(s,t,\tau_2).
\]

The selected history feature set adds current and earlier same-station rainfall
to station identity, cyclic time and the rainfall threshold. All predictor
information is anchored at or before $t$; future readings define only the
outcome. Station selects the same-station history series; prediction time $t$
anchors temporal and historical features; the rainfall threshold is a
numerical input and defines the exceedance label. The numerical feature set
contains 36 columns. Station ID is processed separately using StringIndexer
and OneHotEncoder, then concatenated with the numerical predictors to form the
full model vector.

The station encoding retains an explicit unknown category, so a new station
can be scored using its time and rainfall history. Since that category has no
training examples, the model has no learned station-specific effect for it.
Coordinates and future rainfall are excluded from the predictors. Logistic
regression uses standardized inputs; random forest and gradient-boosted trees
use the assembled inputs without standardization.

\subsection{Model selection}
Model development had two stages. Hyperparameters were screened on a
deterministic 10\% sample from 2017 to 2020. Up to two close configurations
per family were then refitted on all 2017 to 2020 training windows and
compared on 2021. The search varied logistic regression
\texttt{regParam} over 0.001, 0.01, 0.1 and 1; random forest
\texttt{(numTrees, maxDepth)} over (50, 6), (100, 6) and (50, 8); and
gradient-boosted tree \texttt{maxDepth} over 3 and 4 and \texttt{maxIter}
over 20 and 40. Within each family, mean PR-AUC across the six primary
thresholds on 2021 selected a configuration; mean Brier score and model
complexity resolved close results.

For the final comparison, LR-A, RF-B, GBT-A and GBT-B were fitted on the same
deterministic 10\% sample of the combined 2017 to 2021 training data.
Climatology rates were estimated from that sample. The climatology baseline
and four ML models were evaluated on the same deterministic 10\% sample of
2022. Mean PR-AUC across the six primary thresholds ranked candidates, with
mean Brier score and model complexity resolving close results
(Table~\ref{tab:selection}).

The climatology baseline uses training examples only. For each threshold,
it estimates an overall exceedance rate, then month-hour and
station-month-hour rates, shrinking each more specific estimate toward its
parent with $\lambda=100$:
\[
  \hat p_{0,\tau}=\frac{X_{0,\tau}}{N_0},\qquad
  \hat p_{m,h,\tau}=\frac{X_{m,h,\tau}+\lambda\hat p_{0,\tau}}{N_{m,h}+\lambda},\qquad
  \hat p_{s,m,h,\tau}=\frac{X_{s,m,h,\tau}+\lambda\hat p_{m,h,\tau}}{N_{s,m,h}+\lambda}.
\]
Here $X_{g,\tau}$ is the number of training examples in group $g$ whose
future 30-minute rainfall is greater than threshold $\tau$, and $N_g$ is the
total number of training examples in that group. An empty station-month-hour group
therefore uses its month-hour rate; if that group is also absent, the estimate
falls back to the overall rate.

0.01466 to 0.01402, but its sampled fit took 383.5 rather than 255.9 seconds.

\subsection{Final fitting, calibration and monotone prediction}
After selection, a new GBT-B model was fitted on all 34,541,470 valid
2017-2022 base windows (207,248,820 threshold-expanded rows). An isotonic
calibrator, shared across all six thresholds, was fitted on a deterministic
10\% sample of the 2023 calibration partition:
671,768 of 6,719,274 base windows, expanded to 4,030,608 threshold examples.
On this calibration sample, ECE decreased from 0.02264 before calibration to
0.00165 after calibration. The final GBT fit took
12,286.9 seconds (about 3 hours 25 minutes).

After calibration, the equal-weight pool-adjacent-violators algorithm
(PAVA)~\cite{deleeuw-pava} was
applied to the six anchor probabilities
$[0.2,0.5,1,2,5,10]$~mm. The projection minimizes squared displacement subject
to a non-increasing probability sequence. Any requested threshold inside
$[0.2,10]$~mm is estimated by linear interpolation between projected anchors;
out-of-domain thresholds are rejected.

\subsection{Feature-family importance}
For the final GBT-B model, Spark split importances were mapped from encoded
vector indices to feature families and normalized by total importance.
Current rainfall contributed 45.02\%, followed by threshold at 23.40\%,
rolling maxima at 10.27\% and rolling totals at 10.24\% (Figure~\ref{fig:feature-family}).
Station identity had no split importance in this fitted model. Split
importance reflects impurity reductions from the fitted trees, not causal
effects. Correlated rainfall-history features can share importance.

Together, current rainfall, rolling totals and maxima, wet counts and rainfall
lags account for 72.92\% of total split importance. The trees therefore rely
mainly on the station's recent rainfall state, consistent with the large
Set B improvement in model selection. The threshold's 23.40\% share has a
different meaning: it specifies which exceedance question is being asked.
It is an essential input to the shared model, not a meteorological cause
of rainfall.

Time of day and seasonal cycle contribute 3.09\% and 0.59\%, respectively.
These smaller shares do not contradict Task 1's daily pattern; recent rain
can be more informative about the next half-hour than the average pattern
for that hour.

At a 0.5 probability cutoff, precision and recall were 74.2\% and 52.7\%
for the 0.5~mm target, falling to 58.6\% and 19.3\% at 10~mm. Thus, most
heavy exceedances were missed despite ROC-AUC remaining near 0.90.
PR-AUC also declined as exceedances became rarer, from 0.6345 at 0.5~mm

was not selected as an optimal warning rule.

Weighted ECE is the count-weighted absolute gap between mean predicted
probability and observed frequency in each probability bin, aggregated over
ten equal-width bins at each threshold:
\[
  \mathrm{ECE}_{w}=\frac{1}{N}\sum_{\tau}\sum_{b=1}^{10}
  n_{\tau b}\left|\bar p_{\tau b}-\bar y_{\tau b}\right|,
  \qquad N=\sum_{\tau,b}n_{\tau b}.
\]
Here $n_{\tau b}$ is the bin count, $\bar p_{\tau b}$ the mean predicted
probability and $\bar y_{\tau b}$ the observed exceedance frequency.
Final weighted ECE was 0.001670, slightly higher than climatology's
0.001425. Climatology therefore had a smaller binned calibration error,
despite worse discrimination and Brier error. Calibration alone does not
measure how well a predictor separates high-risk from low-risk windows.

At 0.5~mm, 94.75\% of final predictions fall in the lowest probability bin,
with mean prediction 1.35\% and observed frequency 1.24\%
(Figure~\ref{fig:reliability}). This large group dominates weighted ECE.
The 0.4--0.5 bin shows a larger error: mean probability 43.28\% versus
observed frequency 32.71\% across 12,426 windows. Agreement is closer in the
highest bin, at 95.53\% versus 94.96\%. Thus, low average calibration error
coexists with overprediction in parts of the middle range. ECE for this
single rainfall threshold is 0.00250; Table~\ref{tab:monotonicity} aggregates
all six thresholds.

\section{Discussion and limitations}
Calendar patterns describe when rainfall is generally more likely, while
recent observations provide the main improvement for individual forecasts.
The remaining weaknesses are exceedances after no observed rain and heavy
accumulations even when rain is already recorded.

Task 1 comparisons remain sensitive to the changing station network.
Task 2 was evaluated on one held-out year, using stations already seen in
training; performance at new stations is untested. Separately, the dataset
does not record when revised observations became available, so retrospective
event-time evaluation does not establish real-time performance.

Useful follow-up work would evaluate station and seasonal subgroups and
separate complete dry histories from incomplete ones. For a warning
application, a lower probability cutoff could recover more exceedances,
but its false-positive burden should be assessed on validation data.

\section{Conclusion}
This project developed an end-to-end Spark workflow for analysing Singapore
rainfall patterns and predicting 30-minute rainfall exceedance probabilities
from NEA five-minute observations. For Task 1, we cleaned and audited the
2017-2024 records, accounted for missing observations and changing station
coverage, and analysed annual, monthly and hourly rainfall patterns.
Wet-reading frequency ranged from 1.94\% to 3.20\%, with a consistent
afternoon peak across most years. Because the monitoring network changed over
time, these results are interpreted as patterns in the observed network
rather than as a fixed-station climate trend.

For Task 2, we constructed a temporally separated training, validation,
calibration and test pipeline using station, time, rainfall threshold and
recent same-station rainfall history. The selected GBT model was retrained on
34.5 million valid 2017-2022 windows and evaluated on 6.37 million held-out
2024 windows. At the 0.5~mm threshold, the final model achieved a PR-AUC of
0.6345 and a Brier score of 0.01958, compared with 0.0732 and 0.03436 for the
climatology baseline. Adding recent rainfall history was the main source of
improvement, increasing the 2022 GBT mean PR-AUC from 0.0355 to 0.5221.
Isotonic calibration improved probability calibration, and the final PAVA
projection removed cross-threshold monotonicity violations.

The full pipeline was executed on a distributed Google Cloud Dataproc cluster
using Spark DataFrames and MLlib, from data preparation and feature
construction through model fitting and evaluation.
